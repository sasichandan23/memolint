Record it yourself

  1. Terminal at 18pt or larger, dark theme, nothing else on screen.
  2. Start capture with Win+Alt+R.
  3. Run memolint replay docs/demo-transcript.ansi --speed 1.4 --countdown 3.
  4. Record the voiceover separately, reading to picture.
  5. Cut to music and burn in the captions above.
This is a preview of the terminal track only, so there is no music, no talking head and no B-roll. Every line on screen came from a real run against Hindsight and Groq. The full shot list, titles and thumbnail prompt are in docs/VIDEO.md.
