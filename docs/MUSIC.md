# Music and licensing

The edit ships with `docs/track.wav`, a phonk-style backing track generated by
`scripts/make_beat.py`. It is synthesised from sine waves, filtered noise and
saturation, so no recording was sampled, nothing needs clearing, and Content ID has
nothing to match. Regenerate it at any tempo:

```bash
python scripts/make_beat.py --bpm 150 --bars 82 --out docs/track.wav
```

## Using a real track instead

Pick one that grants the licence before you use it, not after. These give a written
licence up front and carry plenty of phonk and drift phonk:

- Pixabay Music, https://pixabay.com/music/ - free for commercial use, no attribution required
- Uppbeat, https://uppbeat.io/ - free tier with attribution, per-track licence page
- YouTube Audio Library, in YouTube Studio - cleared for use on YouTube by definition
- Free Music Archive, https://freemusicarchive.org/ - check each track's Creative Commons terms

Then render against it:

```bash
python scripts/beat_edit.py --bpm <track tempo> --audio path/to/track.mp3 --out docs/memolint-edit.mp4
```

Set `--bpm` to the track's actual tempo or the cuts will drift out of time. If you do not
know it, tap it out against the track or read it from the download page.

## Why not just use an unlicensed phonk track

Two practical reasons, before the legal one.

A claim lands on the video, not on you. Content ID mutes or blocks playback, and it does it
whenever the match is detected, which can easily be the week judges are watching. Second,
absence of a claim today is not permission: plenty of phonk is built on uncleared samples,
so the track being unflagged says nothing about whether the rights exist to grant.

Asking afterwards does not fix it either. Permission is what makes the use lawful, so it has
to come first. If you want a specific artist's track, mail them before the submission and use
the generated track until they reply.
